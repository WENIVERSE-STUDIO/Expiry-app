# 만료일 비서 (expiry-app)

한 번 등록하면 알아서 알려주는 생활 만료일 비서 — WENIVERSE LAB 첫 번째 실험.

화장품 개봉일, 쓰레기 배출일, 계약·서류 만료일, 구독 결제일을 한 곳에서 D-day로 관리합니다.
서버 없이 동작하는 PWA(홈 화면에 설치되는 웹앱)이며, 데이터는 사용자 기기에만 저장됩니다.

## 기능 (v0.2)

- 분류: 🧴 화장품 · 🗑️ 생활 · 📄 계약·서류 · 💳 구독·결제
- 분류별 프리셋 — 예: 마스카라 3개월, 세럼 6개월, 여권 10년, 음악 스트리밍 1개월
- 일회성(개봉일 + 기간)과 반복(매주·매달) 일정
- 남은 날짜 순 정렬, 지남 / 곧 만료 / 여유 색상 구분 (분류별 임박 기준: 화장품 14일, 계약 30일, 구독 3일, 생활 1일)
- "새로 시작" — 새 제품 개봉·계약 갱신 시 시작일을 오늘로
- 앱을 열 때 하루 한 번 임박 항목 요약 알림
- 📅 캘린더 연동 — 기본 캘린더(.ics: 아이폰·삼성·네이버) 또는 구글 캘린더 링크.
  임박 기준일·당일 오전 9시 알림과 반복 규칙이 함께 들어가 앱을 열지 않아도 캘린더가 알려줌
- 오프라인 동작, 홈 화면 설치

## 실행

```bash
npm start     # http://localhost:8000
npm test      # 날짜 계산 단위 테스트 (Node 20+)
```

서비스 워커 때문에 `index.html`을 파일로 직접 열지 말고 로컬 서버로 여세요.

## 구조

```
index.html            화면
css/style.css         스타일 (라이트/다크 자동)
js/app.js             화면 렌더링, 등록·수정·삭제, 알림
js/dates.js           날짜 계산 (말일 보정, 반복 일정, D-day)
js/categories.js      분류별 기본값·프리셋 — 프리셋 추가는 여기서
js/calendar.js        캘린더 연동 (.ics 생성, 구글 캘린더 링크)
sw.js                 오프라인 캐시 (파일 변경 시 VERSION 올리기)
manifest.webmanifest  PWA 설정
tests/                단위 테스트
```

## 배포

비공개 저장소이므로 Vercel / Netlify / Cloudflare Pages에 저장소를 연결해 배포합니다 (빌드 설정 없음).
PWA 설치와 알림은 HTTPS 주소에서만 동작합니다.
